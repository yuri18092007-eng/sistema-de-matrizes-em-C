# sistema-de-matrizes-em-C

Calculadora de Matrizes em C

Descrição:
Sistema desenvolvido em linguagem C para cadastrar duas ou mais matrizes e realizar operações matemáticas entre elas.

Funcionalidades:
- Cadastro de duas ou mais matrizes.
- Definição de linhas e colunas.
- Preenchimento individual dos elementos.
- Adição de matrizes.
- Subtração de matrizes.
- Multiplicação de matrizes.
- Divisão matricial utilizando matriz inversa.
- Validação das dimensões.
- Identificação de matrizes singulares.
- Menu interativo para novas operações.

Tecnologias utilizadas:
- Linguagem C.
- Biblioteca stdio.h.
- Biblioteca stdlib.h.
- Biblioteca math.h.

Como executar:

1. Instale um compilador C, como GCC.
2. Abra o terminal na pasta do projeto.
3. Compile o programa:

gcc main.c -o calculadora -lm

4. Execute:

Windows:
calculadora.exe

Linux:
./calculadora

 Limitações
- Máximo de 10 matrizes cadastradas.
- Máximo de 10 linhas e 10 colunas por matriz.
- A divisão exige matriz divisora quadrada e inversível.
